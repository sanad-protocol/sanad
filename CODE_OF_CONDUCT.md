# Code of conduct

This project follows the **Contributor Covenant, version 2.1** (<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>), which is incorporated here by reference.

In short: be respectful and constructive; accept criticism of work graciously; do not harass, demean or discriminate; do not publish other people's private information; assume good faith and say plainly when you disagree.

## Reporting

Report violations to contact@sanadprotocol.org. Reports are treated confidentially. The steward may warn, restrict or remove participants after hearing them. Because the project is run by one person for now, a report about the steward may be sent to the stand-by person named in the governance charter once one has been appointed.

## Scope

This code applies to all project spaces: the repositories, the issue tracker, discussions and public events held in the project's name.
